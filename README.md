# AI Writer Assistant — Chrome Extension

A Google-Translate-style **floating bubble** that brings the AI Writer Assistant to every page you visit. Companion extension to the AI Writer Assistant Gemini web app.

Select any text on a page, tap the bubble, and it **translates automatically**. The panel also fixes grammar, rewords in 9 tones, defines words, and scores your writing — powered by **Google Gemini or any OpenAI-compatible provider**, with **auto model fetching** and **smart page context**.

## Features

| Tab | What it does |
|---|---|
| **Translate** | 3 nuanced translations (Standard / Formal / Casual) with auto language detection, language swap, and text-to-speech |
| **Fix** | Grammar & spelling correction + up to 2 stylistic alternatives, each with explanations |
| **Reword** | 3 rephrased variations in a chosen tone (Professional, Creative, Diplomatic, Concise, Casual, Friendly, Humorous, Sarcasm, Ancient) |
| **Define** | Dictionary lookup: definition, clickable synonyms, usage example |
| **Coach** | Clarity score (1–100 ring), detected tone, strengths, and suggestions |

### The bubble

- **Click** — toggles the panel (auto-fills with your page selection and translates)
- **Drag** — move it; position is saved per browser and survives reloads
- **Resize** — set the bubble diameter (36–64 px) in **Options → Bubble & context**
- **Right-click** — hide it (with an *Undo* toast, or re-enable in Options)
- **Toolbar icon** — toggles the panel on/off on the current tab
- **Esc** closes the panel · **Ctrl+Enter** runs the current action

Everything renders inside a **Shadow DOM**, so host-page CSS can never break the UI, and the bubble never runs in iframes.

## Icon & bubble color themes

The brand system is a **premium black, white and cream** palette: warm paper surfaces, near-black ink and a glossy floating sphere. The mark is drawn as a floating bubble — glossy gradient sphere with a sheen, a cream "spark", and a small satellite bubble. Seven themes ship in `icons/<theme>/`, switchable in **Options → Icon & bubble color**:

**Black (default) · White · Indigo · Sky · Emerald · Rose · Amber**

Picking a theme recolors three things at once: the toolbar icon (`chrome.action.setIcon`), the in-page floating bubble, and the panel logo. The white theme gets a warm gray edge so it stays visible on light toolbars; the black theme uses a warm charcoal gradient with a cream spark and satellite. Icons are generated by `tools/gen-icons.cjs` (zero dependencies, 3×3 supersampled spark rasterizer) — edit the `THEMES` table there to add your own colors, run `node tools/gen-icons.cjs`, and the new theme appears in Options automatically (add it to `ICON_THEMES` in `options.js`, `background.js` and `BUBBLE_THEMES` in `content.js`).

## AI providers

Choose the provider in **Options → AI Provider**:

### Google Gemini (default)
Same models and prompts as the web app (`gemini-3-flash-preview` for everything, Pro-tier for the Coach tab, automatic fallback to `gemini-*-latest` aliases if preview names are retired).

### OpenAI-compatible
Any endpoint that speaks `POST /v1/chat/completions`:

| Provider | Base URL |
|---|---|
| OpenAI | `https://api.openai.com/v1` |
| OpenRouter | `https://openrouter.ai/api/v1` |
| Groq | `https://api.groq.com/openai/v1` |
| Together | `https://api.together.xyz/v1` |
| Ollama (local) | `http://localhost:11434/v1` |
| LM Studio (local) | `http://localhost:1234/v1` |

One-click presets fill the base URL. The extension requests JSON mode (`response_format: json_object`) when the provider supports it and transparently retries without it when it doesn't; the required JSON shape is always described in the system prompt, and responses are parsed leniently.

### Auto model fetching
Model dropdowns are **fetched live from the provider** — `GET /v1/models` for OpenAI-compatible endpoints and Gemini's `ListModels` API (filtered to text-generation models). Fetch happens automatically when the Options page opens with credentials present, or via the **Fetch models** button. Separate models can be picked for the Coach tab (deeper analysis) vs. everything else.

## Smart context

When enabled (Options, or the document icon in the panel header), each request includes a compact context block:

- page title and site domain
- the page's declared language (`<html lang>`)
- the text **surrounding your selection** (its containing paragraph, ±220 chars)

The prompt tells the model to use it *only* to disambiguate meaning, tone, idioms and audience — never to translate it. Example: *"I need to go to the bank"* selected on a river-rafting article translates to the riverbank reading (किनार), not the financial one.

Additional smart touches:

- **Detected source language** shown above translations when using Auto-detect
- **No-op translation guard** — selecting Japanese text with Japanese target auto-flips the target to English (unambiguous scripts only)
- Context is capped (title 120 chars, surrounding 500) and can be toggled off per-panel with one click

## Install (unpacked)

1. Open `chrome://extensions`
2. Enable **Developer mode** (top-right)
3. Click **Load unpacked** and select this repository folder
4. Open the extension's **Options**:
   - **Gemini**: paste your key from [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey), then **Test key**
   - **OpenAI-compatible**: pick a base-URL preset, paste the key, **Fetch models**, pick a model
5. Set your default language pair (defaults: Auto-detect → Nepali, matching the web app)

> Keys are stored only in `chrome.storage.sync` in your browser and sent only to the endpoints you configure. No key is bundled with this repo — optionally, developers can create a local `config.local.js` (git-ignored) containing `self.AIWA_DEFAULT_KEY = 'AIza…';` to have a default key without committing it.

## Architecture

```
ai-writer-assistant-chrome-extension/
├── manifest.json     MV3: storage permission; broad host permissions for custom API endpoints
├── background.js     Service worker — provider router (Gemini REST + OpenAI chat completions),
│                     model fetching, smart-context prompt building, message routing
├── content.js        Bubble + panel UI (Shadow DOM), selection & context capture, TTS, drag
├── options.html/js   Provider settings, model fetching, key testing, languages, toggles
├── icons/            Generated brand icons (7 themes)
└── tools/gen-icons.cjs  Dependency-free PNG icon generator (node tools/gen-icons.cjs)
```

**Message flow:** `content.js` → `chrome.runtime.sendMessage({type:'GEMINI_TASK', payload})` (payload includes text + optional `pageContext`) → `background.js` routes to the configured provider, injecting the JSON schema (Gemini) or a shape description (OpenAI-compatible) → response rendered as cards.

The prompts and JSON schemas are ported 1:1 from the web app's `services/geminiService.ts`, so both produce the same style of results regardless of provider.

## Notes & limits

- Works on `http://` and `https://` pages; Chrome system pages (`chrome://`, Web Store) can't host content scripts — the toolbar icon opens Options there instead.
- Selections are capped at 8,000 characters to keep prompts fast.
- `host_permissions` covers `http://*/*` and `https://*/*` so you can point the extension at any API host, including `localhost`. No analytics, no remote code, no build step.
